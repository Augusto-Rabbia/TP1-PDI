# Trabajo Práctico 1 - Procesamiento de imágenes

Se trata de un proyecto donde implementamos ecualización de histogramas y validamos un archivo de formulario utilizando segmentación.

## Instalación
Clonar el repositorio
```bash
git clone https://github.com/Augusto-Rabbia/TP1-PDI.git
```
Ejecutar 
```bash
python ecualizacion_local.py
python validacion_formulario.py
```

## Instrucciones de uso

Al ejecutar el archivo `ecualizacion_local.py`, se mostrará automáticamente el resultado de la aplicación de la técnica.

Al ejecutar el archivo `ecualizacion_local.py`, se le pedirá ingresar el path del archivo con la imágen a analizar.
Una vez especificado, devolverá cuáles de los campos es correcto.
